# Map data

The Geography view draws the India outline from `india.geojson` in this folder.

Use boundaries consistent with the official Survey of India depiction. The
[DataMeet community maps](https://github.com/datameet/maps) project publishes them
(see its `Country` folder). Download the country GeoJSON, save it here as `india.geojson`, and commit it.

Credit shown on the page: "Boundaries: DataMeet, following the Survey of India depiction."

If the file is missing, the view still works: it plots flagged cities on a plain frame and says so.
